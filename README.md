# E-Commerce Revenue & Customer Intelligence Analytics

## Run
```bash
pip install pandas numpy
python src/01_generate_data.py
python src/02_analysis.py
```

The project generates 500,000+ transactions and Power BI-ready CSV files in `output/`.

## Power BI
Load these files:
- kpi_summary.csv
- monthly_sales.csv
- regional_performance.csv
- product_performance.csv
- rfm_segments.csv
- cohort_retention.csv

Suggested cards: Revenue, Profit, Profit Margin, AOV, Repeat Purchase Rate, Return Rate.
